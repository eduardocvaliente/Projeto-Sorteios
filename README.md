<h1>🎲 Sorteador de Números</h1>
<p>Este é um projeto simples e divertido de sorteio de números, onde o usuário define o intervalo dos números (mínimo e máximo) e o site gera um número aleatório dentro desse intervalo.</p>
<br>
<h2>Funcionalidades</h2>
<ul>
  <li>Campo para inserir o número mínimo</li>
  <li>Campo para inserir o número máximo</li>
  <li>Botão para sortear um número aleatório</li>
  <li>Exibição instantânea do resultado na tela</li>
  <li>Layout responsivo e interface simples</li>
</ul>
